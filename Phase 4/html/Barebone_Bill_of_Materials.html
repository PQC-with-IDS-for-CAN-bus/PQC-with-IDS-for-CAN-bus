TJA1051T/3 to STM32G431 Pinout & Wiring Table

TJA1051 Pin Pin Name Connects To Voltage Function
1 TXD STM32 Pin PB9 3.3V Digital Transmit data from MCU to transceiver
2 GND STM32 Pin GND + CAN_GND 0.0V Common signal and circuit ground
3 VCC STM32 Pin 5V (USB rail) 5.0V DC Powers the high-energy differential bus driver
4 RXD STM32 Pin PB8 3.3V Digital Receive data from transceiver to MCU
5 VIO STM32 Pin 3.3V 3.3V DC CRITICAL: Sets 3.3V logic levels to protect STM32!
6 CAN_L Physical Bus CAN_L 1.5V / 2.5V Negative differential signal line
7 CAN_H Physical Bus CAN_H 2.5V / 3.5V Positive differential signal line
8 S Tie to GND 0.0V Disables silent mode; enables bidirectional CAN-FD

Open-Source Firmware Flashing & Deployment Guide

  1. Zero Programmer Cost: The STM32G431 chip includes a factory ROM USB DFU bootloader. No ST-Link debugger hardware required.
  2. DFU Mode Entry: Hold down the BOOT0 tactile button on the WeAct board, plug into laptop USB-C, then release BOOT0.
  3. Flash Firmware: Open STM32CubeProgrammer, select USB mode, load precompiled weact_g431_candlelight.bin, and click Start Programming at address 0x08000000.
  4. Linux Auto-Enumeration: Plug into Raspberry Pi 5 USB ports. Mainline Linux kernel gs_usb driver instantly binds them as can0 and can1.
  5. Windows Laptops: Run Zadig (free, 30-second setup), select device, install WinUSB driver. Native Python python-can communicates via interface='gs_usb'.
Critical Engineering Safeguard: The NXP TJA1051T/3 transceiver requires two separate power connections: Pin 3 (VCC) must be connected to 5.0V to power the high-speed differential CAN-FD driver, while Pin 5 (VIO) must be connected strictly to 3.3V to clamp RXD logic pulses to safe microcontroller levels. Pin 8 (S) must be tied to GND to disable Silent Mode.
